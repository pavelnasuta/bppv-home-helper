# Личный помощник при позиционном головокружении

Статическое русскоязычное приложение для локальной записи наблюдений у взрослого человека с ранее диагностированным ДППГ. Не ставит диагноз, не отправляет медицинские данные в сеть и не заменяет очную помощь.

## Важно

- При новых неврологических симптомах, потере сознания, внезапной сильной головной боли или боли в шее после травмы — прекращайте действия и обращайтесь за экстренной помощью (в РФ: 112/103).
- Текущая сборка — технический прототип с клиническим контентом `unreviewed`.
- Пошаговый домашний манёвр Эпли намеренно закрыт до независимой проверки клиницистом правил, схем и текстов. Опрос, ручная запись, история и экспорт остаются доступны.

## Запуск

Нужен Node.js 22+.

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Production-сборка создаётся в `dist/`. Для локального просмотра сборки:

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Откройте `http://127.0.0.1:8080`. Не используйте `file://`: service worker и IndexedDB должны работать через HTTP.

## Данные и резервная копия

Записи сохраняются в IndexedDB текущего браузера. Разные браузеры, localhost и GitHub Pages не синхронизируются. Экспорт JSON не шифруется: храните файл как медицинские сведения. В репозиторий и GitHub Actions данные пациента не попадают.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает приложение и публикует `dist/` после push в `main`. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions**. Сборка для Pages автоматически использует путь `/bppv-home-helper/`.

## Офлайн

После первой успешной загрузки service worker кэширует оболочку приложения. Статус подключения не считается доказательством офлайн-готовности; перед реальным использованием проверьте приложение с отключённой сетью.

## Проверка контента

См. `CLINICAL_REVIEW.md` и `ACCEPTANCE.md`. Медицинские правила и схемы нельзя считать клинически согласованными, пока их не проверит профильный специалист.
